# 안녕하세요, 김혜윤입니다 👋

> 기능 구현뿐만 아니라  
> 시스템 전체의 구조와 데이터 흐름에 관심이 많습니다.  
> 서버, AI, 클라이언트가 연결되는 과정을 직접 구성하고  
> 전체 흐름을 이해하려고 노력하고 있습니다.

C/C++ · Linux 기반의 서버 구조 설계를 중심으로 학습하고 있으며,  
최근에는 AI 추론 서버 · 웹 백엔드 · 이벤트 소싱 구조까지 영역을 확장하고 있습니다.

---

## 🧩 관심 분야

- **시스템 흐름** — 단일 기능보다 Client · Server · AI · DB가 연결되는 전체 구조에 집중합니다.
- **이벤트 기반 아키텍처** — epoll · EventBus · asyncio 기반의 비동기 처리 구조를 직접 설계하고 비교해보고 있습니다.
- **구조와 기준의 명확화** — 기능 구현 이전에 프로토콜 · 디렉터리 · 데이터 흐름을 팀이 통일된 시각으로 바라볼 수 있는 기준 정리를 중요하게 생각합니다.

---

## ⚙️ Working Principles

여러 팀 프로젝트를 진행하며 정리한 세 가지 기준입니다.

| | 원칙 | 의미 |
|---|---|---|
| 01 | **역할과 기준의 명확화** | 역할 흐름을 먼저 나누고, 프로토콜 · 디렉터리 · 데이터 흐름까지 통일된 기준을 정리합니다. |
| 02 | **끝까지 추적하는 시스템 관점** | 기능 동작에서 끝나지 않고, Client · Server · AI · DB의 연결 흐름을 끝까지 확인합니다. |
| 03 | **일관된 흐름을 우선** | 빠른 구현보다, 구조와 기준이 일관된 상태에서 작업을 이어갈 수 있는 흐름을 우선합니다. |
